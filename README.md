# ZomIA Formulario Briefing Móvil

Formulario HTML optimizado para móvil que recopila briefings comerciales con guardado automático.

## ✨ Características

- ✅ Guardado automático (localStorage)
- ✅ Barra de progreso dinámica
- ✅ Descarga CSV automática
- ✅ Resumen modal
- ✅ 100% responsivo (móvil)
- ✅ Sin dependencias externas

## 🚀 Usar

Abre `index.html` en tu navegador.
